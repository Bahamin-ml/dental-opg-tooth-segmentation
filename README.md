\# Dental OPG Tooth Segmentation



A deep learning project for automated tooth segmentation in panoramic dental X-ray (OPG) images using PyTorch.



\## Project Overview



This project focuses on semantic segmentation of teeth in panoramic dental X-ray images using deep learning techniques.



\## Technologies



\- Python

\- PyTorch

\- NumPy

\- OpenCV

\- Matplotlib

\- Image Segmentation



\## Project Files



\- `Dental OPG notebook.ipynb` — Complete project implementation and experiments.

\- `dental\_opg\_ablation\_E\_SE\_Dropout.pt` — Trained PyTorch model weights.



\## Getting Started



1\. Clone this repository.

2\. Install the required Python dependencies.

3\. Open the notebook using Jupyter Notebook.

4\. Load the trained model weights for inference.
